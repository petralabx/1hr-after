# Raw sources

Immutable layer of the Karpathy wiki. See [`../wiki-schema.md`](../wiki-schema.md).

Drop research here. Do not edit a file after it is committed. Agents read sources and write the summary into [`../knowledge/`](../knowledge/).

Suggested folders as material arrives (create the folder with the first file, not before):

| Folder | What lands here |
|---|---|
| `external-research/` | Articles, briefs, and clippings a human adds |
| `meta-ads/` | Exported ad-account reports, creative reviews, pixel diagnostics |
| `audits/` | SEO/AEO or site audits |

Do not commit exports that contain access tokens, customer lists, or cost-of-goods data.
